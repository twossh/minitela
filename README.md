# MiniTela

Aplicativo Linux nativo para gerenciamento da tela auxiliar do
Positivo Vision R15M.

## Objetivos

- Monitor de sistema
- Clima
- Imagem personalizada
- Controle de brilho
- Detecção automática da MiniTela
- Reconexão automática
- Restaurar a última tela utilizada
- Inicialização automática com o sistema
- Funcionamento nativo no Linux
- Distribuição em AppImage
